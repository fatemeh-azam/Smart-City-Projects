# Sensor Code

This folder contains code developed for the sensors and sensor hardware used in the Smart City Monitor project.



When adding code, please create a subfolder if your code contains multiple files or belongs to a specific sensor or hardware platform. Keep related files together and use clear, descriptive names.

Example:

```text
sensors/
├── README.md
├── XIAO ESP32-S3/
│   └── ...
├── dht22/
│   └── ...
└── MAX30102/
    └── ...
```

Please do not add passwords, API keys, `.env` files, or other sensitive information to this folder.
